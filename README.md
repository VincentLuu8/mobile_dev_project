# Personal Restaurant Guide

Android app built for COMP3074 which helps users to keep track of the restaurants they visit,
rate them and share freely.

---

## Features
- Add new restaurants
- Edit existing entries
- Remove restaurants
- Store:
    - Name
    - Address
    - Phone number
    - Description
    - Tags
    - Rating (1–5 stars)
- Open the restaurant’s location in Google Maps
- Share restaurant details by Email, Facebook, and Twitter
- Search restaurants by name
- Filter by tags

### Screens
- Splash screen with app logo
- Main screen for adding restaurants
- Restaurant list screen with search
- Details screen with share + navigation options
- Edit screen for updating existing restaurants
- About screen with team member names

---

## How to Run

1. Clone this repository.
2. Open the project in **Android Studio**.
3. Let Gradle sync and install any required dependencies.
4. Run the app on an emulator or a physical Android device.
